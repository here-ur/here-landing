# here 랜딩페이지

here 서비스 소개 페이지입니다. 빌드 없이 `index.html`과 `img/`만으로 열리는 정적 페이지입니다.

- 주소: https://here-ur.vercel.app (Vercel `here-landing` 프로젝트, `main`에 머지하면 자동 배포됩니다)
- 원본: Claude 아티팩트 [HERE 랜딩페이지](https://claude.ai/artifact/F2D1Zgm2rsD4r5X3WmvYUr) (2026-11-23 버전). 지금은 이 저장소가 기준입니다.
- 보기: `index.html`을 브라우저로 열면 됩니다.
- 고치기: 브랜치를 만들어 `index.html`을 고치고 `main`으로 PR을 보냅니다. PR마다 Vercel 미리보기 주소가 생성됩니다.
- 서비스는 별도 저장소(`here-ur/here`)입니다. "시작하기" 버튼은 운영 서비스(`here-prod.vercel.app`)로 연결됩니다.
